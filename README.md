## 🚀 Features

<p align="center">
  <img src="https://drive.google.com/uc?export=view&id=1NnFvzCxQCH3yKiuCxewf7nklAB2iAJMl" width="250"/>
  <img src="https://drive.google.com/uc?export=view&id=1WIWGF2CIn4vTjs1GU_Rv-tM2IvbWQZdY" width="250"/>
  <img src="https://drive.google.com/uc?export=view&id=1RuBRIujk720F-TZUJc0Au_qBZGxiQEJU" width="250"/>
</p>
This app creates small, cute bees flying on your screen, allowing you to interact with them to quickly translate the content you want. Each bee has a special power!

* **Full screen**: Translate all content on the screen

* **Crop Screen**: Translate the selected screen zone

* **Auto Subtitle**: Auto translate subtitles that appear in videos

* **Auto Audio**: Auto translate audio played on the device's speaker

* **Dictionary Lookup**: Look up the full meaning of a word on the screen

* **Bookmark**: Allow store vocabulary and sync words from local to cloud.

## 📦 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/leetoneee/bubble_translation.git
   cd bubble_translation
   ```

2. **Open in Android Studio**
   - Open the `BubbleTranslation` folder using Android Studio.
   - Allow Gradle to sync and download dependencies.
   - Ensure your SDK and build tools are up to date.

3. **Build and Run**
   - Connect an Android device or start an emulator.
   - Click the Run button or use `./gradlew installDebug` from the command line.

4. **Permissions**
   - The app requires overlay permissions to display the translation bubble.
   - Grant the necessary permissions when prompted.
